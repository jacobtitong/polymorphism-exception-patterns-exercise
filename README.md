# Parcel Delivery System

A Java console program that lets you add parcels (Document, Box, Fragile), pick a delivery service (Standard, Express, Same Day), view all parcels, change a parcel's service, and mark parcels as delivered.

- **Name:** Jacob D. Titong
- **Section:** C2B

## How to Run

1. Open the `src` folder in VS Code.
2. Open Main.java and run the file.
